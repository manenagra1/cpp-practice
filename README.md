# cpp-practice

A collection of beginner-friendly C++ programs and small projects created while learning the fundamentals of programming.

This repository documents my progress, practice, and growing understanding of C++ through hands-on projects.

## Projects

### Calculator

Performs basic arithmetic operations, including addition, subtraction, multiplication, and division.

### Guessing Game

A simple interactive game in which the user attempts to guess a randomly generated number.

### Odd or Even

Determines whether a number entered by the user is odd or even.

### Multiplication Table

Generates and displays the multiplication table for a number provided by the user.

### Student Grade Manager

Calculates and manages student grades using basic data handling and arithmetic operations.

### Temperature Converter

Converts temperatures between Celsius and Fahrenheit.

## Concepts Practiced

These projects provide practice with:

* Variables and data types
* User input and output
* Arithmetic and mathematical operations
* Conditional statements
* Loops and iteration
* Functions
* Random number generation
* Basic data management
* Input validation
* Problem-solving and program logic
